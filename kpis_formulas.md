## KPIs & Fórmulas (Campos Calculados)

Este documento lista os principais KPIs (Key Performance Indicators) utilizados no Sistema CMO as a Service, juntamente com suas respectivas fórmulas de cálculo.

*   **CPL (Custo por Lead):**
    *   `CPL = Investimento / Leads`

*   **CTR (Click-Through Rate):**
    *   `CTR = Cliques / Impressões`

*   **CVR (Conversion Rate):**
    *   `CVR = Vendas / Cliques` (ou `Leads / Visitas`)

*   **ROAS (Return on Ad Spend):**
    *   `ROAS = Receita / Investimento`

*   **ROI (Return on Investment):**
    *   `ROI = Lucro / Investimento`

*   **CAC (Custo de Aquisição de Cliente):**
    *   `CAC = Investimento de Aquisição / Novos Clientes`

*   **LTV (Lifetime Value):**
    *   `LTV = Ticket médio × nº compras × margem`

*   **Payback:**
    *   `Payback = CAC / Margem mensal`

*   **Show (Sala Secreta):**
    *   `Show = Presentes / Inscritos`

*   **Conv (Sala Secreta - Conversão):**
    *   `Conv = Vendas / Presentes`
