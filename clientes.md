## Base de Dados: Clientes

**Campos Chave:**

*   **Nome:** Nome do cliente.
*   **Início:** Data de início do contrato.
*   **ICP_OK:** (sim/não) Indica se o cliente atende ao Perfil de Cliente Ideal.
*   **Trafego_min_ok:** (sim/não) Indica se o cliente possui tráfego mínimo.
*   **Margem_ok:** (sim/não) Indica se o cliente possui margem de lucro adequada.
*   **Time_ok:** (sim/não) Indica se o cliente possui time mínimo.
*   **Contrato:** Duração do contrato (e.g., 6-12 meses).
*   **Decisor:** (sim/não) Indica se o decisor está presente.
*   **Status:** Status atual do cliente (Ativo, Inativo, Pausado, etc.).
